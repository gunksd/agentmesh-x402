## 录完怎么给我

**方式一（推荐）：分段录 17 个文件**

命名 `01.m4a` … `17.m4a`，放进 `docs/voice/`。逐段匹配，对齐最精确。

**方式二：整轨录一个文件**

任意格式（m4a / wav / mp3），告诉我路径即可。我按静音间隔切分，可能需要微调。

拿到音频后我做三件事：

1. 测量你每段的实际时长，把画面切换点对齐到语音
2. 重新生成中英双语字幕，跟着新时间轴走
3. 合并输出 mp4

## 念稿提示

- 数字按口语写好了（「零点一四五美元」「一百七十九个」），照读即可
- 英文术语按习惯读法：x402 念「x four zero two」或「x四零二」都行，EIP-712、Permit2、BscScan 按英文读
- 不用刻意停顿等画面，以语音为准来调画面
